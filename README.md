# Морьтон Үржүүлэг — азарганд гүү тавих захиалгын сайт (GitHub Pages + Firebase)

Сайт нь **GitHub Pages** дээр (үнэгүй, статик), өгөгдөл нь **Firebase Firestore** дээр (Google, үнэгүй Spark төлөвлөгөө) хадгалагдана. Сервер шаардлагагүй.

- `index.html` — 19 азарганы каталог
- `azarga.html?id=…` — азарга, захиалгын маягт
- `zahialga.html?code=GT-…` — захиалгын төлөв, баталгаажуулалтын маягт (хэвлэх, QR)
- `admin.html` — админ (Firebase имэйл/нууц үгээр нэвтэрнэ)

Азарга бүр 10 гүү (админаас өөрчилж болно). Баталгаажих бүрт суудал хасагдаж, 10/10 болоход тухайн азарга автоматаар хаагдана.

---

## 1. Firebase тохируулах (≈10 минут, нэг удаа)

1. **https://console.firebase.google.com** → **Add project** → нэр: жишээ нь `moriton-urjuulleg` (Google Analytics хэрэггүй). *Морьтон эмнэлгийн төслөөс тусад нь үүсгэ.*
2. **Build → Firestore Database → Create database** → *Production mode* → байршил: `asia-east2 (Hong Kong)` эсвэл `asia-northeast1 (Tokyo)`.
3. **Firestore → Rules** таб → энэ фолдер дахь `firestore.rules` файлын агуулгыг бүхэлд нь хуулж тавина → **Publish**.
   - Файлын эхэнд `adminEmails()` жагсаалтад админ имэйлүүдийг бичнэ (одоо `khongor95@gmail.com`). Өөр ажилтан нэмэх бол `'нэр@gmail.com',` гэж мөр нэмээд дахин Publish.
4. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
   **Users → Add user** → админ имэйл + нууц үг (rules-д бичсэн имэйлтэй ижил).
5. **Project settings (⚙) → General → Your apps → Web (`</>`)** → нэр өгөөд Register → гарч ирсэн `firebaseConfig = { … }` утгуудыг `js/firebase-config.js` файлд хуулж тавина.
6. **Authentication → Settings → Authorized domains → Add domain** → `ТАНЫ-НЭР.github.io`.

## 2. GitHub дээр байршуулах

1. https://github.com → **New repository** → нэр: `azarga` → **Public** → Create.
2. **Add file → Upload files** → энэ фолдерын бүх файл/фолдерыг чирж оруулна → **Commit changes**.
   GitHub нэг удаад 100 файл авдаг тул: эхлээд `img` фолдероос бусдыг, дараа нь `img` фолдерыг тусад нь upload хий.
3. Repo → **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. 1–2 минутын дараа сайт: `https://ТАНЫ-НЭР.github.io/azarga/`

## 3. Эхний ажиллуулалт

1. `…/azarga/admin.html` → имэйл, нууц үгээр нэвтэрнэ.
2. **«Анхны тохиргоо — азарга импортлох»** товч → 19 азарга Firestore-д орно (нэг л удаа).
3. **Тохиргоо** таб → утас, хаяг, улирал, маягтын нөхцөл, **дансны мэдээлэл** (банк, дансны дугаар, хүлээн авагч, IBAN) — захиалагчид төлбөрийн хэсэгт энэ л харагдана.
4. **QR постер** таб → сайтын QR-тай A4/A5 постерыг хэвлэж (эсвэл PDF, PNG татаж) тараана.
5. Утаснаасаа туршилтын захиалга өгч, «Шилжүүлсэн» дараад админаас баталгаажуулж, маягтыг хэвлэж шалгаад туршилтын захиалгыг цуцална.

## 3а. Төлбөрийн урсгал (дансаар)

1. Захиалагч азарга сонгож бүртгүүлмэгц захиалгын хуудсанд **төлөх дүн** (үржүүлгийн үнэ × гүүний тоо, хямдрал тооцсон), **дансны мэдээлэл**, **гүйлгээний утга = захиалгын код** гарна. Private үнэтэй азаргад «утсаар тохиролцоно» гэж гарна.
2. Захиалагч банкны аппаараа шилжүүлээд **«✓ Шилжүүлсэн»** дарна → админ имэйл рүү мэдэгдэл очно, админ самбарт 💳 тэмдэг гарна («💳 Шилжүүлсэн — шалгах» шүүлтүүр).
3. Админ дансны хуулгаас кодтой гүйлгээг шалгаад **Баталгаажуулах** дарна → суудал хасагдаж, захиалагчийн хуудас өөрөө шинэчлэгдэн **баталгаажуулалтын маягт** («✓ Төлөгдсөн» тэмдэгтэй) гарна.
4. 24 цагийн дотор баталгаажаагүй захиалга автоматаар «хугацаа дууссан» болно (админ нэвтрэх үед цэвэрлэгдэнэ); шаардлагатай бол «↩ Хүлээгдэх» товчоор сэргээнэ.

## 4. Аюулгүй байдал (firestore.rules хамгаалдаг)

| Хэн | Юу хийж чадна |
|---|---|
| Хэн ч | Азарга, сайтын тохиргоо харах; **зөвхөн «хүлээгдэж буй»** захиалга үүсгэх (талбар, утасны хэлбэр, гүүний тоо 1–5, суудал хүрэлцэх эсэх, идэвхтэй азарга эсэх шалгагдана) |
| Кодоо мэддэг хүн | Зөвхөн өөрийн захиалгыг харах (`GT-` + 6 тэмдэгт ≈ 1 тэрбум хувилбар, таах боломжгүй); хүлээгдэж буй захиалгадаа **«Шилжүүлсэн»** тэмдэг (зөвхөн `transferClaimedAt`, `payerName` 2 талбар) тавих |
| Админ (rules-ийн имэйл) | Бүх захиалга харах, баталгаажуулах/цуцлах, азарга засах, тохиргоо |

- Захиалагчийн утас, нэр GitHub-д **ороxгүй** — зөвхөн Firestore-д. Азарганы хуудсанд дараалал «Б. Д.» гэж товчлон харагдана.
- `firebase-config.js` дахь түлхүүрүүд нууц биш (Firebase-ийн бүх веб сайтад ил байдаг) — хамгаалалт нь rules.
- Баталгаажуулалт транзакцаар хийгддэг тул хоёр админ зэрэг дарсан ч 10-аас хэтрэхгүй.

## 5. Нөөцлөлт, зардал

- Админ → **⬇ Excel (CSV) татах** — улирлын явцад 7 хоног тутам татаж хадгал.
- Spark (үнэгүй): өдөрт 50,000 унших / 20,000 бичих — энэ сайтад хангалттай.
- Найдвартай байдлыг нэмэх бол Blaze төлөвлөгөө (хэрэглээгээрээ, энэ хэмжээнд ~0$) асааж Firestore → **Disaster recovery → Point-in-time recovery** асаана.

## 6. Засвар хийх

- **Текст, үнэ, багтаамж, идэвх** → admin.html (кодод гар хүрэх шаардлагагүй).
- **Зураг солих** → `img/<slug>-a.jpg` (том) ба `img/<slug>-a-s.jpg` (жижиг, ~640px) файлыг GitHub дээр ижил нэрээр солих.
- **Шинэ азарга** → `data/seed-stallions.json`-д нэмээд зургийг `img/`-д хийгээд admin дээр «Анхны тохиргоо» товчийг дахин дарна (байгаа азаргыг хөндөхгүй, зөвхөн шинийг нэмнэ). *Товч нь азарга хоосон үед л харагддаг — шинэ азарга нэмэх бол Claude-аас туслалцаа ав.*

## 7. Хуучин (локал) хувилбар

Дээд фолдер дахь `server.js` + `start.bat` хувилбар (интернэтгүй, нэг компьютер/Wi-Fi дотор) хэвээр ажиллана. Хоёулаа **тусдаа өгөгдөлтэй** — нэгийг нь сонгож ашигла.
